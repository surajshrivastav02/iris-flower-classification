# Iris Flower Classification 🌸

A first machine-learning project that trains a Decision Tree classifier to predict the species of an Iris flower from four measurements.

## Features
- Loads the classic Iris dataset from scikit-learn
- Splits data into training and testing sets
- Trains a Decision Tree model
- Reports accuracy and classification report
- Predicts a species for a sample flower

## Tech stack
Python, Pandas, Scikit-learn

## Setup
```bash
python -m pip install -r requirements.txt
```

## Run
```bash
python iris_classifier.py
```

The Iris dataset is included with scikit-learn, so no separate dataset download is needed.

## Learning outcomes
Understand features and labels, train/test split, classification, model accuracy, and predictions.
